# AI Smart Agriculture Decision Agent

A multi-agent agriculture decision system combining crop images, soil, weather, irrigation, pest/disease risk, and market conditions.

## Features
- 🌱 Crop & Field Profile Management
- 📸 Crop Image Analysis
- 🌤️ Weather-Aware Recommendations
- 🌍 Soil and Irrigation Analysis
- 🐛 Disease and Pest Risk Assessment
- 📊 Market and Price Intelligence
- 💡 Integrated Farm Decision Generation
- 🔍 Explainable Recommendations
- 💬 Farmer Feedback System
